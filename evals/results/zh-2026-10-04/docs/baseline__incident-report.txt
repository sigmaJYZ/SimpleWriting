**故障报告：部分 API 请求返回 502 错误**

**状态：已解决**

2026 年 10 月 4 日 14:02 至 14:31 UTC 期间，约 12% 的 API 请求返回了 HTTP 502 错误。受影响的用户可能遇到请求失败或响应不稳定的情况。

**原因：** 14:02 开始的一次部署意外去掉了缓存预热步骤，导致服务在缺少预热缓存的情况下承接流量，部分请求因此失败。

**处理过程：** 我们发现错误率上升后定位到该次部署，并在 14:27 将其回滚。随后各项指标逐步恢复，14:31 起 API 已完全恢复正常。

**后续措施：** 我们会把缓存预热设为部署流程中的必需检查项，缺失时部署将被自动拦截，并完善相关告警，以便更早发现类似问题。对于由此造成的不便，我们深表歉意。
