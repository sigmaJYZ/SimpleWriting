# sqlpipe v2.0 发布说明

sqlpipe v2.0 带来了一项不兼容的接口变更、一个新参数，以及明显的写入性能提升。

## ⚠️ 不兼容的变更

**`/v2/users` 的 `name` 字段已拆分为 `first_name` 和 `last_name`。**

`name` 字段不再返回，也不再接受。依赖该字段的客户端需要在升级前完成适配：

- 读取时：改为分别读取 `first_name` 和 `last_name`，需要完整姓名时自行拼接。
- 写入时：请求体中分别提供这两个字段。

## 新功能

**新增 `--incremental` 参数。** 启用后，sqlpipe 只处理自上次运行以来发生变化的数据，不再每次全量同步，适合定时任务和大表场景，能有效缩短运行时间并降低资源消耗。

```bash
sqlpipe run --incremental
```

## 性能优化

**Parquet 写入速度提升 40%。** 导出到 Parquet 的任务现在更快完成，无需修改任何配置，升级后自动生效。

## 升级建议

升级前请先检查所有调用 `/v2/users` 的代码和脚本，确认已适配 `first_name` / `last_name`，再切换到 v2.0。
