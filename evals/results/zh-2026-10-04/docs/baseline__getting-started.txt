## 快速开始

本节将带你在几分钟内安装 sqlpipe，并完成第一次运行。

### 1. 安装

在终端中执行以下命令：

```bash
curl -sSL https://get.sqlpipe.dev | sh
```

安装完成后，运行 `sqlpipe --version` 确认安装成功。如果提示找不到命令，请重新打开终端，或检查安装目录是否已加入 `PATH`。

> 提示：该脚本会直接在本机执行。如果你希望先确认内容，可以先下载脚本检查后再运行。

### 2. 配置 sqlpipe.yaml

sqlpipe 通过配置文件来定义任务。在当前目录新建 `sqlpipe.yaml`，写入你的数据源、目标以及要执行的内容。请根据自己的环境填写连接信息，具体字段请参阅配置参考。

建议：

- 不要把密码等敏感信息直接写进配置文件，可以通过环境变量传入。
- 第一次使用时，先选择一个小的数据范围，便于快速验证结果。

### 3. 第一次运行

配置完成后，执行：

```bash
sqlpipe run --config sqlpipe.yaml
```

sqlpipe 会读取配置、连接数据源并开始执行。运行过程中，终端会输出进度和日志；任务结束后，你可以在目标位置检查结果是否符合预期。

如果运行失败，请先查看终端中的错误信息，通常是配置路径不对、连接信息有误或网络不通所致。
